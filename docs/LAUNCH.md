## 2. 실서비스 신뢰도 (소액·결정 필요)

### 2-1. 주소를 lostkorea로 — ✅ 완료(2026-11-09)
- **lostkorea.com** 구입: Cloudflare Registrar, 연 $11.17(원가, 쿠폰·할인 없음 — 첫해만 싼 곳들은 갱신가가 높아 5년 합계 차이가 ~$9뿐이라
  매년 같은 가격·관리 편의로 선택). 2027-11-09 만료, **자동 갱신 켬**. 등록자 정보는 공개 WHOIS에서 가려짐.
- DNS A `@`·`www` → 서버, **Cloudflare 프록시 켬**(SSL Full (strict), Always Use HTTPS 끔 — 이유는 DEPLOY.md 'Cloudflare 앞단').
- 서버 `.env`에 새 주소(대표)·www·옛 주소. **www와 옛 주소(findit-lost.duckdns.org)는 새 주소로 영구 이동** — 이미 보낸 알림 메일·
  대회 자료의 옛 링크도 그대로 동작. 가동 감시(`uptime.yml`)도 새 주소로.
- 확인(11/9): `https://lostkorea.com` 200, `http://` → `https://`(308), `www`·옛 주소 → 새 주소(301), canonical·sitemap·OG 모두 새 주소.
- **속도(이 PC에서 12회씩, 매번 새 연결)**: 홈 화면 중앙값 프록시 1.09초 vs 서버 직접 1.23초로 비슷하지만, **느린 쪽 10%가 프록시 4.96초
  vs 직접 1.27초** — 무료 요금제라 한국 접속이 미국 LA의 Cloudflare 서버를 거침. 화면이 자주 느리면 DNS only로 되돌리는 것 검토.
- `.kr`(선택): Cloudflare는 .kr을 팔지 않음 → 가비아 등 국내 업체(블로그 기준 연 2만 원대). 사칭 방지용, 급하지 않음.

### 2-2. Gemini API 유료 등급 — ✅ 이미 유료(확인 2026-11-14)
**현황(11/14)**: 결제 계정이 **유료 1**(선불 크레딧, 9/14 ₩10,000 충전 → 11/14 잔액 ₩7,644, openclaw 프로젝트와 공유),
**자동 충전 켬**(11/14). 운영·로컬 키는 같은 키(끝 `qrSA`). 처리방침은 고칠 것 없음(제품 개선 사용 언급 없음).
비용 추정: 색인 임베딩 글이 1건 평균 36자라 늦은 등록 채우기 기간 하룻밤 ~₩150, 평소 하루 수십 원 + 신고 1건 ~₩6.

(아래는 전환 전 메모)
신고 문장·사진을 Gemini로 보내는 서비스다. Google의 Gemini API 약관상 **무료 등급은 입력이 Google 제품 개선에 쓰일 수 있고,
유료 등급은 쓰이지 않는다**(전환 전에 현재 약관을 한 번 더 확인할 것). 실사용자 데이터를 받는다면 유료 등급이 맞다.
→ Google AI Studio에서 결제 연결. 전환 후 알려주시면 개인정보처리방침 문구를 그에 맞게 고쳐 드림.

### 2-3. 개인정보 보호책임자 명시 — ✅ 완료(2026-11-14)
개인정보보호법상 처리방침에는 **개인정보 보호책임자의 성명(또는 담당 부서)·연락처**가 들어가야 한다.
**✅ 연락처는 완료(11/14)**: Cloudflare Email Routing(무료)으로 `privacy@`·`help@lostkorea.com` → 운영자 Gmail 전달,
처리방침·약관·바닥글의 문의를 GitHub Issues → 이메일로. Gmail에서 두 주소는 "스팸으로 보내지 않음" 필터 권장
(첫 시험 메일 'test'가 내용 때문에 스팸 분류됨 — 전달 자체는 정상).
**✅ 성명(11/14)**: 처리방침 8장 '개인정보 보호책임자: 최장호(운영자, 개인)' + privacy@ 연락처(한·영).

### 2-4. 알림 메일 발송 방식
지금은 개인 Gmail SMTP — 하루 발송 한도(약 500통)가 있고, 개인 주소가 보내는 사람으로 노출된다.
**결정(11/14)**: **Maileroo 무료(월 3,000통·시간당 30통·카드 불필요)** — Cloudflare Email Sending은 사용자에게 보내려면
Workers Paid(월 $5) 필요해서 제외, Brevo 무료는 메일에 로고가 붙을 수 있어 제외. 코드는 준비 완료(FIND-94): `SMTP_FROM`·`SMTP_REPLY_TO`,
알림 메일에 '알림 그만 받기' 링크 + 원클릭 수신 거부 헤더(RFC 8058).
**진행(11/14)**: ✅ Maileroo 가입·`lostkorea.com` 인증(Active) — SPF는 기존 줄에 합침(`v=spf1 include:_spf.mx.cloudflare.net include:_spf.maileroo.com ~all`),
DKIM `mta._domainkey`(2048비트), DMARC `v=DMARC1; p=none` / ✅ 보내는 주소 `LostKorea <notify@lostkorea.com>`(답장은 Email Routing으로 Gmail)
/ ✅ 처리방침 위탁·국외이전 갱신(Gmail → Maileroo, Cloudflare 추가, 시행일 11/14) / ✅ 서버 `.env` 전환·시험 발송(spf·dkim·dmarc pass)
/ ✅ 운영 알림 주소(`NOTIFY_EMAIL_TO`)가 예시 문구였던 것 고침 / ✅ Maileroo 열람·링크 추적 끔 → 대신 '메일 링크로 결과 열람' 횟수만 사이트가 셈(FIND-96).
⏳ 무료는 **시간당 30통**(월 3,000통) — 알림이 몰리면 나눠 보내기·한도 상향 필요.

### 2-5. 사업자 등록 — 지금은 불필요

- **비용 상한**: 하루 AI 사용 상한(`DAILY_AI_BUDGET=1500` 단위 ≈ 글 신고 1,500건)이 있어, 남용·폭주가 있어도 하루 최대 약 $6로 묶인다.

  임베딩 API가 없어 임베딩은 Gemini 등을 계속 써야 하고(키·국외 이전 대상 2곳), 한국어 판정 품질을 같은 질의로 비교한 적이 없다.

## 5. 규모가 커지면 (지금은 불필요)
- **동시 사용자 증가**: 지금은 단일 프로세스. 워커를 늘리려면 레이트리밋 저장소를 Redis로(`apps/api/limits.py`).
- **백업 외부 복제**: 지금은 같은 서버에 14일. 신고가 쌓이기 시작하면 암호화해서 외부 저장소로.
- **에러 추적 고도화**: 지금은 오류 메일(1시간 1통). 오류가 잦아지면 Sentry 등.
- **카카오 알림톡**: 사업자 등록 후. **이미지 임베딩(CLIP)**: 사진 검색 정확도 향상.
