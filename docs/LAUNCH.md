## 1. 이번 주 (무료, 각 5~30분)

### 1-1. DB 비밀번호 교체 — ✅ 완료(2026-11-09)
공개 레포에 적힌 기본값(`findit_pw`)이던 것을 무작위 값으로 교체(서버 `.env`에만 저장, 옛 값은 접속 거부 확인).
이제 compose에 기본값이 없어 비밀번호 없이는 뜨지 않는다. 다시 바꾸는 절차는 DEPLOY.md 8-2.

### 1-2. 검색엔진 등록 (30분) — 노출의 시작 · **주소를 lostkorea로 옮긴(2-1) 뒤에** 하는 게 효율적
지금까지 검색엔진에 사이트를 알린 적이 없다. sitemap·메타는 준비됨. 등록은 주소 단위라, 지금 duckdns 주소로 등록하면
새 주소로 옮길 때 다시 해야 한다 → 주소를 먼저 옮기고 그 주소로 등록.
- **Google Search Console** (search.google.com/search-console): 속성 추가 → 소유 확인(HTML 태그 방식이면 알려주시면 head에 넣어 드림)
  → `sitemap.xml` 제출. 외국인은 구글로 검색한다.
- **네이버 서치어드바이저** (searchadvisor.naver.com): 한국어 사용자·국내 노출용. 같은 방식.
- **Bing Webmaster Tools**: Google Search Console에서 가져오기로 1분.

### 1-3. `.env` 사본 보관
`.env`(API 키·비밀번호)는 GitHub에 없다. 서버가 날아가면 같이 사라지므로 비밀번호 관리자 등에 한 부.

## 2. 실서비스 신뢰도 (소액·결정 필요)

### 2-1. 주소를 lostkorea로 (가장 먼저)
지금 주소 `findit-lost.duckdns.org`는 서비스 이름과 다르고, 무료 동적 DNS라 신뢰도·검색 순위·메일 도달률에도 불리하다.
두 가지 길(둘 다 코드 수정 없음 — 주소 목록·대표 주소·옛 주소 영구 이동을 설정값으로 바꿀 수 있게 해 둠):

| | 무료 임시: `lostkorea.duckdns.org` | 정식: `lostkorea.com` (+`.kr`) |
|---|---|---|
| 비용 | 0원 | 연 1~2만 원 |
| 준비 | DuckDNS(지금 findit-lost를 만든 계정)에서 서브도메인 `lostkorea` 추가, **IP를 서버 IP로**(DuckDNS가 기본으로 넣는 건 지금 PC의 IP라 꼭 바꿀 것) | 가비아·Cloudflare·Namecheap 등에서 구입 → DNS A 레코드를 서버 IP로 |
| 상태(11/9 조회) | 미사용 | .com·.kr·.app 모두 미등록 — 남이 먼저 살 수 있음 |

주소가 준비되면(서버 이전 FIND-83 이후) 서버 `.env`:
```bash
DOMAIN=lostkorea.duckdns.org, findit-lost.duckdns.org      # 새 주소 + 옛 주소(둘 다 인증서 자동 발급)
PUBLIC_BASE_URL=https://lostkorea.duckdns.org               # 대표 주소(메일 링크·canonical·sitemap)
REDIRECT_HOSTS=findit-lost.duckdns.org                      # 옛 주소 → 대표 주소 영구 이동(옛 링크·검색 기록 유지)
```
→ `docker compose -f docker-compose.prod.yml up -d backend caddy` → `.github/workflows/uptime.yml`의 `BASE` 한 줄 → 1-2 검색엔진 등록.
정식 도메인을 나중에 사면 같은 방식으로 한 번 더(옛 주소들을 `REDIRECT_HOSTS`에 추가).

### 2-2. Gemini API 유료 등급 전환 (사용량 기반, 현재 규모면 월 수천 원 이하 예상)
신고 문장·사진을 Gemini로 보내는 서비스다. Google의 Gemini API 약관상 **무료 등급은 입력이 Google 제품 개선에 쓰일 수 있고,
유료 등급은 쓰이지 않는다**(전환 전에 현재 약관을 한 번 더 확인할 것). 실사용자 데이터를 받는다면 유료 등급이 맞다.
→ Google AI Studio에서 결제 연결. 전환 후 알려주시면 개인정보처리방침 문구를 그에 맞게 고쳐 드림.

### 2-3. 개인정보 보호책임자 명시
개인정보보호법상 처리방침에는 **개인정보 보호책임자의 성명(또는 담당 부서)·연락처**가 들어가야 한다.
지금은 "운영자(개인) · GitHub Issues"라 실서비스 기준으로 부족. 이름(또는 직함)과 연락용 이메일을 정해 주시면 반영.
도메인을 사면 `privacy@도메인` 같은 주소를 만들 수 있다.

### 2-4. 알림 메일 발송 방식
지금은 개인 Gmail SMTP — 하루 발송 한도(약 500통)가 있고, 개인 주소에서 오는 자동 메일은 스팸함에 가기 쉽다.
도메인을 사면 발송 서비스(Resend·Amazon SES 등, 소량 무료)로 바꾸고 SPF/DKIM을 설정하는 게 정석. 코드는 `EmailNotifier` 한 곳만 바꾸면 됨.

### 2-5. 사업자 등록 — 지금은 불필요
수익(광고·후원·유료 기능)이 없으면 의무 아님. 다만 **카카오 알림톡**(한국 사용자 알림의 사실상 표준)·기관 제휴 계약·후원을 하려면 필요.

## 3. 사용자 유입 — 가장 중요 (시간 필요)

사람이 LostKorea가 필요한 순간은 **물건을 잃어버린 직후**다. 그 순간 그 사람이 보는 곳에 있어야 한다.

| 채널 | 왜 | 할 일 |
|---|---|---|
| 구글 검색 | "lost wallet Seoul", "lost and found Korea" 검색 | 1-2 등록 + `/en/guide` 가이드가 이 질문에 답함. 가이드를 더 늘리면(공항·택시·지하철별) 노출 증가 |
| 외국인 커뮤니티 | 분실 직후 도움을 구하는 글이 실제로 올라옴 | Reddit r/korea·r/seoul·r/koreatravel, 페이스북 외국인 그룹, 유학생 단톡방 — **광고 말고 그런 질문에 답하면서 링크** |
| 대학 국제처 | 유학생 수만 명, 분실 문의가 들어옴 | 국제처·외국인 학생회에 안내 요청(무료 서비스·개인정보 처리 방식 설명) |
| 숙소 프런트 | 게스트가 분실하면 프런트에 묻는다 | 게스트하우스·호텔에 QR 안내 한 장 |
| 기관 | 신뢰도·규모 | 관광안내소·1330·지자체 외국인 지원센터에 소개 — 데이터랩 분석(외국인 방문 59.2%·습득물 38.1% 집중)이 근거 자료 |

- 효과 확인: 주간 요약 메일의 `방문(영어)`·`영어 가이드 방문`·`신고(글/사진)`.
- 공유 미리보기(OG 이미지)는 준비됨 — 링크를 붙이면 카드가 뜬다.

## 4. 운영비 — 실측 기반 (2026-11-09, FIND-78 이후)

Gemini 3.6 Flash 유료 등급 기준(입력 $0.75 · 출력 $3.75 / 100만 토큰, **2027-01-01부터 2배** 예정), 1달러 ≈ 1,400원.

| 항목 | 토큰(실측) | 비용 |
|---|---|---|
| 글 신고 1건(한국어: 추출+노선+판정 12후보) | 입력 ~1,630 · 출력 ~700 | 약 **$0.004 (≈5원)** — thinking을 끄기 전엔 ~$0.014 |
| 글 신고 1건(외국어: 판정에 영어 이름·설명 추가) | 출력 ~1,100 | 약 $0.005 (≈7원) |
| 사진 신고 | 이미지 토큰 + 사진 있는 후보 대조 | 글 신고의 몇 배(미실측) |
| 재매칭 1회(새 후보가 들어온 열린 신고만) | 판정 1회 | 약 $0.0025 |
| 수집 임베딩(하루 ~4천 건 × ~20토큰) | 월 ~240만 | **월 약 $0.4 (≈500원)** |

| 하루 글 신고 | 월 AI 비용(지금 가격) | 2027 가격 |
|---|---|---|
| 10건 | 약 1,600원 | 약 3,200원 |
| 100건 | 약 1.6만 원 | 약 3.3만 원 |
| 1,000건 | 약 16만 원 | 약 33만 원 |

- **비용 상한**: 하루 AI 사용 상한(`DAILY_AI_BUDGET=1500` 단위 ≈ 글 신고 1,500건)이 있어, 남용·폭주가 있어도 하루 최대 약 $6로 묶인다.
- 고정비는 서버(VPS 월 요금)와 도메인뿐. Gemini를 무료 등급으로 쓰면 AI 비용은 0이지만 입력이 Google 제품 개선에 쓰인다(2-2).
- **모델 선택 메모**: Claude Haiku 5.5는 토큰 단가가 Gemini 3.6 Flash의 약 1/7.5(입력 $0.10 · 출력 $0.50)이지만
  임베딩 API가 없어 임베딩은 Gemini 등을 계속 써야 하고(키·국외 이전 대상 2곳), 한국어 판정 품질을 같은 질의로 비교한 적이 없다.
  → 하루 신고가 수백 건이 되거나 2027년 Gemini 가격이 오를 때, 판정만 Haiku로 바꿔 같은 질의 A/B 측정 후 결정.
- **임베딩은 유지**: 월 500원 수준인데 검색 품질의 핵심(키워드 검색 MRR 0.633 → 임베딩 0.960, 영어 질의는 키워드로 0건).

## 5. 규모가 커지면 (지금은 불필요)
- **동시 사용자 증가**: 지금은 단일 프로세스. 워커를 늘리려면 레이트리밋 저장소를 Redis로(`apps/api/limits.py`).
- **백업 외부 복제**: 지금은 같은 서버에 14일. 신고가 쌓이기 시작하면 암호화해서 외부 저장소로.
- **에러 추적 고도화**: 지금은 오류 메일(1시간 1통). 오류가 잦아지면 Sentry 등.
- **카카오 알림톡**: 사업자 등록 후. **이미지 임베딩(CLIP)**: 사진 검색 정확도 향상.
