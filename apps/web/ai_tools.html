AI 앱에서 LostKorea 쓰기

MCP 연결 · English

Claude 같은 AI 앱에 아래 주소를 연결하면, AI가 직접 전국 경찰서·유실물센터에 들어온 습득물을 찾아 줘요. MCP는 AI 앱이 바깥 도구를 쓰는 공통 규격이에요. 가입 없이 주소만 붙여 넣으면 돼요.

MCP 주소
https://lostkorea.com/mcp

연결하기

  • Claude(웹·데스크톱): 설정 → 커넥터 → 사용자 지정 커넥터 추가 → 이름 'LostKorea', 주소에 위 MCP 주소. (쓸 수 있는 요금제는 Claude 쪽 정책을 따라요.)
  • Claude Code: 터미널에서 한 줄
    claude mcp add --transport http lostkorea https://lostkorea.com/mcp
  • Cursor 등: MCP 설정 파일에
    { "mcpServers": { "lostkorea": { "url": "https://lostkorea.com/mcp" } } }
    그 밖의 앱은 '원격(HTTP) MCP 서버 주소'를 넣는 칸에 위 주소를 넣으면 돼요.

할 수 있는 일

도구하는 일
find_matches분실 신고(어느 언어든)를 이 사이트와 같은 AI 매칭에 넣어 후보·점수·근거·보관 기관·전화·원본 링크를 받아요. 신고는 저장하지 않아요.
search_found_items키워드·지역·날짜로 습득물을 찾아요(전체 습득물 화면과 같음).
get_found_item습득물 하나가 지금도 경찰서에 있는지(보관중·종결) 확인해요.

이렇게 물어보세요 — "어제 홍대입구역 2호선에서 검정 카드지갑을 잃어버렸어. LostKorea로 찾아 줘", "강남구에 들어온 에어팟 보여 줘", "이 습득물 아직 경찰서에 있어? F2026111800003998"

한도와 주의할 점

  • 키 없이 쓰면 하루 AI 매칭 3건까지예요(한 번에 3건). 습득물 찾기·상태 확인은 시간당 60번까지.
  • 결과는 AI가 고른 후보예요. 내 물건인지는 보관 기관에 전화하거나 찾아가 직접 확인해야 해요.
  • 신고 문장의 전화번호·카드번호 등은 AI로 보내기 전에 가려요. 처리 방식은 개인정보처리방침을 따라요.

기관 키 신청

분실물을 다루거나 외국인을 응대하는 기관은 키를 받아 더 많이 쓸 수 있어요(한 번에 10건, 하루 300건부터).

  • 대상: 경찰서·지구대, 지하철·철도·버스·공항 유실물센터, 놀이공원·백화점 같은 큰 시설, 관광안내소·관광통역안내, 대사관·영사관, 호텔·게스트하우스, 분실물 관련 공익·연구 목적의 대학·연구소·비영리 단체.
  • 받을 수 없음: 개인(키 없이 하루 3건으로 써 주세요), 결과를 되팔거나 대량으로 모으려는 곳.
  • 신청: {{HELP_EMAIL}}로 기관 이름·담당자·기관 메일·쓰는 목적·하루 예상 건수를 보내 주세요. 확인한 뒤 기관 메일로 키를 보내 드려요.
  • 조건: 결과는 후보이며 주인 확인은 보관 기관에서 해요 · 신고 문장에 필요 없는 개인정보를 넣지 않아요 · 결과를 재배포·판매하지 않아요 · 어기면 키를 회수해요(이용약관).
  • 키 쓰기: Claude(웹·데스크톱)처럼 주소만 넣는 앱은 커넥터 주소를 https://lostkorea.com/mcp?key=키로 넣어요. 이 주소는 키와 같으니 남에게 보이지 않게 해 주세요. 머리글을 넣을 수 있는 앱은 X-MCP-Key: 키. Claude Code라면
    claude mcp add --transport http lostkorea https://lostkorea.com/mcp --header "X-MCP-Key: <키>"
